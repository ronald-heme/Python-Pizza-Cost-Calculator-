# 🍕 Pizza Cost Calculator

A Python console application that allows users to customize a pizza order and automatically calculates the final cost.

## Project Highlights

✅ Four pizza size options

✅ Multiple topping selections

✅ Student discount calculation

✅ Delivery fee calculation

✅ Custom tip percentage calculation

✅ Detailed receipt generation

The program generates a detailed receipt showing all charges and the final total.

## 🛠 Coding Techniques Used

-Python<br>
-Conditional Statements (if, elif, else)<br>
-Loops (while)<br>
-Lists<br>
-User Input Handling<br>
-Arithmetic Operations

## ▶️ Running

1 - Clone: "git clone https://github.com/ronald-heme/pizza-cost-calculator.git" <br>
2 - Nav. Proj. Folder: "cd pizza-cost-calculator" <br>
3 - Run: "python pizza_calculator.py"

## 🧮 Logic

1. User selects a pizza size.<br>
2. User chooses toppings until entering 0.<br>
3. Program calculates the subtotal.<br>
4. Student discount is applied if eligible.<br>
5. Delivery charge is added if selected.<br>
6. Tip is calculated based on the updated total.<br>
7. Final receipt is displayed.

## What I've Learned

From completing this project during my time in community college, I learned a great deal about Python programming and how to build an interactive, menu-driven application. Through developing the Pizza Cost Calculator, I gained hands-on experience with user input handling, input validation, conditional statements, loop control, list manipulation, and performing price calculations based on customer selections. I also learned how to organize program logic to handle discounts, delivery charges, and optional tips while maintaining accurate calculations. Additionally, this project helped me improve my ability to format output, generate clear receipts, and implement basic business logic similar to what might be used in a real-world ordering system. Overall, the project strengthened my problem-solving skills and provided valuable practice writing structured, user-friendly Python code.
